# 🏛️ Ordo 2.0 - Unified Educational Management Platform

> **Ordo** - от лат. *"Порядок"* | A comprehensive PWA platform for managing educational institutions (universities and colleges)

---

## 📋 Описание проекта

**Ordo 2.0** — это коммерческий SaaS продукт, представляющий собой единую платформу замкнутого цикла для полного управления образовательным учреждением и корпусом. Система обеспечивает интегрированное управление всеми аспектами деятельности вуза и колледжа в одной платформе.

### ✨ Ключевые особенности

- **🏢 Масштабируемая архитектура** — модульная система, построенная на принципах Clean Architecture
- **📱 Progressive Web App** — работает на любых устройствах, онлайн и оффлайн
- **🔐 Ролевое управление** — 4 уровня доступа с детальной авторизацией
- **🎨 Полная кастомизация** — персональные кабинеты для каждой роли
- **☁️ Мультитенантность** — одна база данных для множества учреждений
- **🧩 Модульный дизайн** — новые функции не ломают существующий функционал

---

## 👥 Роли и функционал

### 1. **Директор** 👔
- Полное управление учреждением
- Доступ ко всем отчётам и аналитике
- Управление персоналом и структурой
- Стратегическое планирование

### 2. **Заместитель директора** 📊
- Управление учебным процессом
- Контроль расписаний и нагрузок
- Промежуточные отчёты
- Координация преподавательского состава

### 3. **Преподаватель** 👨‍🏫
- **Личный кабинет** с полной кастомизацией:
  - 📸 Загрузка фото профиля
  - 📋 Управление портфолио
  - 📚 Просмотр учебной нагрузки
  - 📝 Управление пожеланиями и предпочтениями
  - 📊 Личная аналитика
- Ведение учебной документации
- Взаимодействие со студентами

### 4. **Студент** 🎓
- **Персональный профиль** с кастомизацией
- Просмотр расписания и информации о курсах
- Взаимодействие с преподавателями
- Доступ к учебным материалам
- Отслеживание прогресса

## 🏗️ Архитектура

Проект построен на основе **Clean Architecture** с следующими принципами:

```
┌─────────────────────────────────────────┐
│        Presentation Layer (UI/PWA)      │
├─────────────────────────────────────────┤
│      Domain & Business Logic Layer       │
├─────────────────────────────────────────┤
│      Data & Infrastructure Layer         │
├─────────────────────────────────────────┤
│    Database & External Services          │
└─────────────────────────────────────────┘
```

### Преимущества архитектуры:

✅ **Масштабируемость** — легко добавлять новые модули  
✅ **Модульность** — независимые компоненты системы  
✅ **Тестируемость** — четкое разделение ответственности  
✅ **Maintainability** — простота в поддержке и развитии

## 🚀 Начало работы

### Требования
- Node.js v18+
- Docker (опционально)
- [Добавить другие зависимости]

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/telikuy070-collab/Ordo-2.0.git
cd Ordo-2.0

# Установите зависимости
npm install

# Конфигурируйте переменные окружения
cp .env.example .env

# Запустите приложение
npm run dev
```

### Запуск в Docker

```bash
docker-compose up -d
```
